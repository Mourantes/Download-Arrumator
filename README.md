# Sobre

Você é alguém que não arruma suas pastas frequentemente, principalmente a pasta de downloads, e deixa tudo acumulando? 

Quando você vê tá tudo uma bagunça, e ver cada tipo um por um e decidindo o que fazer com isso demora muito.

O Arrumator serve para amenizar isso, arrumando os arquivos na pasta de download (ou na pasta em que rodar o programa), em diferentes pastas para dar uma amenizada na bagunça.

# Funcionalidades

O sistema possui as seguintes funcionalidades:

- **Criação Pastas**: O código cria diferentes pastas para a armazenagem dos arquivos através de um dicionário, sendo elas:
    - Documentos: pasta que guarda documentos como arquivos do Word, Excel, PowerPoint, arquivos de texto, etc;
    - Fotos: pasta que guarda arquivos de imagens como .png, .jpeg. .jpg, etc;
    - Áudios: pasta que guarda arquivos de áudio como .mp3, .m4a;
    - Vídeos: pasta que guarda arquivos de vídeo como .mp4, .mwv;
    - Executáveis: pasta que guarda arquivos executáveis do Windows, arquivos .exe;
    - Arquivos compactados: pasta que guarda arquivos comprimidos, como .zip, .rar, .7zip;
- **Identificação de arquivos**: O código identifica os arquivos pelo sufixo do arquivo, também sendo referido no dicionário;
- **Movimentação de arquivos**: Após a identificação do arquivo, ele é movido para uma das pastas criadas que sua classificação se encaixa.

# Como rodar a aplicação

Para rodar o projeto, deve baixar o [downloadArrumator.exe](https://raw.githubusercontent.com/Mourantes/Download-Arrumator/refs/heads/main/downloadArrumator.exe) e colocá-lo na pasta/diretório em que deseja arrumar. 

Ao colocar o arquivo no pasta, basta executá-lo que as pastas informadas serão criadas e os arquivos serão movidas para as respectivas pastas.

As pastas que não tem os nomes das criadas não sofrerão mudanças.

Qualquer erro ou caso acredite que uma extensão de um arquivo seu não esteja no dicionário, informe o desenvolvedor.
